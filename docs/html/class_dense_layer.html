Detailed Description

A layer with a matrix to represent weights and a bias vector.

For training, stores the input matrix that passed through it and contains a weights gradient and bias gradient matrix and vector, respectively.

Eigen::MatrixXf DenseLayer::backward ( Eigen::MatrixXf & error_gradients)

Backpropagation.

Calls several functions from backpropagation.hpp to assist in creating a matrix of weight gradients, a bias gradients, and an matrix of error gradients for the next layer. Calls stochastic_gradient_descent() to update the weights in this DenseLayer.

A matrix of error gradients for the next layer to backpropagate.
