◆ image_to_vector()

Eigen::VectorXf image_to_vector ( const std::filesystem::path & input)

Attempt to convert an image at a file path into a vector. Uses greyscale.

This is achieved by taking the image and from left to right and top to bottom, one byte is taken from each pixel and loaded into the vector as a coefficient. We only need one byte because we only need greyscale. The vector is then casted to hold floats instead of integers and normalized to hold reals in [0, 1] instead of integers in [0, 255].

Returns
The image as a normalized vector.
Exceptions
ImageReadErrorIf there was a problem attempting to read the image.
